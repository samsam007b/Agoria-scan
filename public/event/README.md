## 🎨 Optimisation des photos (recommandé)

Pour de meilleures performances web, il est recommandé d'optimiser les photos :
- Largeur recommandée : 1920px pour auditorium.jpg, 1200px pour les autres
- Format : JPEG avec qualité 80-85%
- Outils : TinyPNG, Squoosh, ou ImageOptim
